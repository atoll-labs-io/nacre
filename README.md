# Nacre

Advanced electronic signatures in Rust: CMS and its European profiles (PAdES, CAdES, then ASiC, XAdES, JAdES, COSE), with their validation. Each format is a cargo feature you enable on demand.

Status: framing, no code yet. See `IDEE.md` (in French).
