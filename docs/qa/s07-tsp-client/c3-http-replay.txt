## Script (src/bin/c3_http_replay.rs of a scratch crate depending on the copied crates/nacre-tsp, features http)
```rust
// Criterion 3, hostile TSA: a server that answers every request with the same recorded
// bench response (another nonce, another imprint). What does the caller of the
// TimestampAuthority trait see?
use nacre_core::{DigestAlgorithm, TimestampAuthority};
use nacre_tsp::HttpTsa;
fn main() {
    let url = std::env::args().nth(1).unwrap();
    match HttpTsa::new(&url).timestamp(DigestAlgorithm::Sha256, &[7u8; 32]) {
        Ok(t) => println!("replayed response: TOKEN ACCEPTED {} bytes", t.len()),
        Err(e) => {
            let src = std::error::Error::source(&e).map(|s| s.to_string());
            println!("replayed response: {e} | source: {src:?} | kind {:?}", e.kind());
        }
    }
}
```
