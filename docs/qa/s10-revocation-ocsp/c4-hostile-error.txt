## c4 — a hostile response gives an error, never a panic
tool: ocsp-hostile (scratch crate, source in c0-scratch-source.txt): every truncation, every byte set to 00/7f/80/81/84/ff and every single bit flipped, each through from_der, produced_at, this_update, nonce, check_nonce, check_this_update and status; panics caught with catch_unwind and counted; a mutated input that status() still judges Ok is counted by where the change sits (inside or outside the signed tbsResponseData); then DER bombs through from_der
